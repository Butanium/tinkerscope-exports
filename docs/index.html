read-only

How this works

  • The viewer is a static site: no backend, no key, nothing collected.
  • A pack link installs into your browser (IndexedDB) and stays there. Nothing you open is uploaded anywhere.
  • Any tinkerscope pack works, not just these — point the viewer at your own with ./viewer/?w=<your pack url>, or open the file from disk.
  • Sampling is off: a static site has no backend and no key. To sample the models, run tinkerscope locally against the same pack.

Run one locally instead

mkdir cot-prefilling && cd cot-prefilling && \
  uvx tinkerscope \
  --pack https://raw.githubusercontent.com/Butanium/tinkerscope-exports/main/cot-prefilling.yaml

Viewing needs nothing. Sampling needs a TINKER_API_KEY; the cookbook [inkling] extra the Inkling base model needs is a hard dependency, so any install already has it.
